# 🚀 OrtizDigital

### Accesibilidad web, ciberseguridad y soluciones digitales

OrtizDigital es una iniciativa especializada en ayudar a organizaciones, autónomos y pequeñas empresas a mejorar su presencia digital mediante servicios de accesibilidad web, cumplimiento normativo, ciberseguridad y desarrollo web.

Nuestro objetivo es crear experiencias digitales seguras, accesibles y alineadas con los estándares actuales de calidad y cumplimiento.

---

## 🌐 Servicios

### ♿ Accesibilidad Digital

* Auditorías de accesibilidad web
* Evaluaciones conforme a WCAG 2.1
* Declaraciones de Accesibilidad
* Identificación y corrección de barreras digitales
* Asesoramiento en cumplimiento normativo

### 🔐 Ciberseguridad

* Evaluación de vulnerabilidades
* Análisis de riesgos
* Revisión de controles de seguridad
* Cumplimiento normativo
* Buenas prácticas de seguridad de la información

### 💻 Desarrollo Web

* Páginas web corporativas
* Diseño responsive
* Optimización SEO
* Desarrollo accesible desde el diseño
* Mejora de experiencia de usuario
